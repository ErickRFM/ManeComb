# ManeComb physical-device certification matrix

Run every case from the frozen final `main` SHA. Generate one Release APK from that SHA, record its SHA-256, and use the same file for issues #29, #89 and #108. A CI/debug APK proves build integrity but does not replace the Release APK used for physical certification.

For every failure record: final Git SHA, APK SHA-256, date/time/timezone, device/model/Android version, account and role without credentials, network, expected/observed result, sanitized screenshot/video/logcat/trace ID, and the probable module below.
